REDESIGN WEBSITE PROFIL DESA — FULL UI/UX OVERHAUL

Saya ingin kamu melakukan REDESIGN TOTAL terhadap tampilan website profil desa ini.

Kondisi website saat ini terlihat seperti "AI-generated website / AI slop":
- terlalu banyak gradient
- terlalu banyak card
- terlalu banyak rounded corner
- spacing tidak konsisten
- typography kurang profesional
- hierarchy informasi lemah
- terlalu banyak efek visual yang tidak diperlukan
- desain terasa generik dan tidak memiliki identitas sebagai website resmi desa

TUGAS UTAMA:
Jangan hanya mempercantik tampilan yang sudah ada.
Lakukan evaluasi ulang terhadap seluruh visual system, layout, hierarchy, spacing, typography, warna, component, navigation, section, dan responsive behavior.

Tujuan akhir:
Website harus terlihat seperti website resmi desa yang dibuat oleh UI/UX designer profesional, bukan template AI.

==================================================

Gunakan font modern, readable, dan profesional.

Rekomendasi:
- Heading: Plus Jakarta Sans / Manrope / DM Sans

Pilih SATU kombinasi utama dan gunakan secara konsisten.

Typography harus memiliki hierarchy yang jelas:

H2
H3

Body

- font terlalu bold di semua tempat
- text dengan gradient
- heading yang terlalu besar hanya untuk terlihat keren

Pastikan teks bahasa Indonesia nyaman dibaca.

==================================================
24. BEFORE CODING
==================================================

Sebelum melakukan perubahan kode:

1. Audit seluruh halaman yang ada.
2. Identifikasi masalah UI/UX.
3. Identifikasi component yang bisa dipertahankan.
4. Identifikasi component yang harus dibuat ulang.
5. Buat design system baru.
6. Buat struktur layout baru.
7. Implementasikan redesign.
8. Pastikan seluruh halaman menggunakan design system yang sama.
9. Test responsive.
10. Pastikan functionality lama tetap berjalan.

Jangan melakukan redesign setengah-setengah.

SEMUA HALAMAN HARUS TERASA BERASAL DARI SATU DESIGN SYSTEM.

IMPORTANT EXECUTION RULE:

DO NOT rewrite the entire application blindly.

First inspect:
- project structure
- framework
- existing pages
- reusable components
- routing
- styling architecture
- assets
- current color system
- current typography
- responsive implementation

Then perform the redesign incrementally.

Before replacing any component, determine whether its existing functionality must be preserved.

Do not create fake content just to make the design look better.

Use the existing real content and assets whenever possible.

Do not create unnecessary UI elements merely for visual decoration.

Every visual element must have a purpose.

The final interface should look intentionally designed, not generated from a generic AI website template.
